# GAOKAO 六科学习条目示范库

> [!important] 这个仓库只放“写法示范”，不是 Personal Learning 的真实学习记录
> 这里不预装插件，也不保存真实 Learning Event、复习日期或图片证据。正式使用请切回 `GAOKAO-PERSONAL-LEARNING`，优先用插件创建新条目。成品范例 YAML 里的 `gaokao_id` 仅用于展示格式，不得复制成正式 ID。

## 从零开始

第一次使用请打开：[03-GAOKAO插件从零上手SOP](03-GAOKAO%E6%8F%92%E4%BB%B6%E4%BB%8E%E9%9B%B6%E4%B8%8A%E6%89%8BSOP.md)。

SOP 采用一个最小闭环：

`创建材料 → 十区块与来源校验 → 真实完成 R1 → Today 接续 R2–R5`

图片证据、AI Prompt、自定义 ID 和自动下一篇都属于可选项。只有最小闭环暴露出明确瓶颈时，才加入一个可选项并单独观察收益。

## 最短使用路径

1. 先按 SOP 在 Personal Learning 用插件创建一条正式笔记。
2. 只有不知道怎么写时，才从下方打开同科、同类型的“成品范例”。
3. 需要 AI 整理时，复制通用主 Prompt，并附对应学科/子板块规则，替换方括号内容。
4. 只提供支持当前原子主题的最小来源组。
5. AI 输出后人工核对来源、符号、条件与结论，再写入正式条目。
6. 回到插件完成校验、事件记录和 Today 闭环。

## 成品最低标准

一个正式条目至少应回答：

- 它是什么？
- 在什么条件下成立或适用？
- 如何识别它？
- 如何使用、推导或验证？
- 最容易错在哪里？
- 哪一张图或哪一句原文是证据？
- 下次复习时，能否用一个主动回忆问题检验掌握？

> [!warning] AI 使用边界
> AI 可以整理、提问、比较和改写，但不能替代教材原文、实验数据、标准答案或教师批改。来源不清时写“待核对”，不要补造页码、数据、定义、题号或结论。

## 消融与奥卡姆原则

- 一次只处理一个原子主题和一个主要学习障碍。
- 先跑通最小闭环，再决定是否增加图片、AI、关联或自动化。
- 十个标准正文标题保留，无依据的内容留空；不得省略 Source、可用 Prompt 或合规 Cues 后声称就绪。
- 保留 R1–R5 完整实现；已收尾消融报告仍为 INCONCLUSIVE，本指南不要求重做实验。
- 工程运行成功不等于长期学习有效；长期效果统一留到真实使用后验证。
