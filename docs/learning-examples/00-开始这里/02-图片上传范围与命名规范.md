# 图片上传范围与命名规范

## 先区分两个动作

| 动作 | 用途 | 会不会自动记录学习事件 |
|---|---|---|
| `GAOKAO: Capture image evidence` | 把一张本地 JPEG/PNG 写入六科 18 个模板之一 | 不会 |
| 把图片发送给 AI | 提取、分层并生成待人工核对的 Markdown 候选稿 | 不会，也不得伪造 |

两者可以独立使用。只需要保存原始证据时，不必同时调用 AI；只需要整理已给出的文字时，也不必添加图片。

插件图片流程一次只接收一张 JPEG 或 PNG，最大 25 MiB，并复用 `GAOKAO: Create subject learning note` 的 18 个模板。`knowledge_point` 模板本身就是新知识点，不要求关联另一个知识点；只有 `problem_case` 必须关联当前学科一个唯一有效的已有知识点。先生成确认计划，核对模板、实体类型、默认目录、附件处置、附件路径和笔记路径后，再决定取消或确认写入。完全相同的图片可复用既有受管附件。详细步骤见 [03-GAOKAO插件从零上手SOP](03-GAOKAO%E6%8F%92%E4%BB%B6%E4%BB%8E%E9%9B%B6%E4%B8%8A%E6%89%8BSOP.md#%E6%9D%90%E6%96%99%E5%87%86%E5%A4%87%E4%B8%8E%E5%8D%81%E4%B8%AA%E6%A0%87%E5%87%86%E5%8C%BA%E5%9D%97)。

## 一次上传的推荐范围

通用 Prompt 支持纯文字、照片、截图、多图和混合输入；一次聚焦一个主要 Entity。先核对本次附件清单及同题/多题关系。插件单次捕获仍只接收一张图，不把 AI 多图整理误称为插件批量入库。

### 可以上传

- 当前知识点对应的教材定义、定理、例题页。
- 一道完整题目的题干、图像、本人解答、批改与标准答案。
- 一个实验的目的、装置、步骤、原始数据、现象、误差分析。
- 一篇英语/语文材料的必要上下文、题目与批改依据。
- 为理解当前条目必须保留的相邻页，但要说明其作用。

### 不要上传

- 与当前条目无关的整章、整本书或大量聊天截图。
- 姓名、学校、学号、联系方式、账号、二维码等个人信息；先裁剪或遮挡。
- 只有标准答案却没有题干或语境的孤立截图。
- 模糊、反光、严重倾斜、缺页码或关键区域被裁掉的图片。
- 版权材料的大范围连续扫描；只取完成当前学习任务所需的最小片段。

## 拍摄与裁剪规则

1. 一张图尽量只承担一种用途：题干、解答、批改、实验数据或原文证据。
2. 保留题号、页码、坐标轴、单位、图例、上下标和关键上下文。
3. 裁掉桌面、手指、通知栏和无关页面。
4. 同一题多图按顺序命名；不要依赖相册时间顺序。
5. AI 无法辨认时重新拍摄，不要求它猜。

## 文件命名

```text
YYYYMMDD-学科-主题-来源或用途-序号.ext
```

示例：

- `20260902-math-quadratic-source-01.jpg`
- `20260902-physics-conveyor-diagram-01.png`
- `20260902-chemistry-titration-data-01.jpg`
- `20260902-biology-photosynthesis-result-01.jpg`
- `20260902-english-essay-feedback-01.jpg`
- `20260902-chinese-reading-source-01.jpg`

## 上传时一并提供的文字

```markdown
任务：为【学科/候选模板 ID/主题】生成一条 Obsidian 学习条目 Preview。
图片：[这一张图片的来源与用途]
我的问题或卡点：[没有则写 none]
允许使用：图片中可见内容 + 我补充的文字。
禁止：猜测被裁掉的题干、虚构页码/数据/结论、把答案当作我的掌握情况。
看不清时：原样标记 `[无法辨认：位置]`，并列出需要我补拍的区域。
```

## 学科差异

- 数学：必须保留定义域、参数范围、图形坐标、题号和本人关键步骤。
- 物理：必须保留装置、运动方向、初态、受力信息、单位与正方向约定。
- 化学：必须保留试剂名称/浓度、装置连接、现象、数据表和安全信息。
- 生物：必须保留自变量、因变量、对照、材料、重复、原始结果；不要只传结论。
- 英语：词汇至少保留完整句；写作批改需保留前后句与批注对应位置。
- 语文：阅读至少保留题目所需段落；写作材料需保留完整任务要求和评分限制。

## 图片进入正式条目前的四问

1. 这张图证明或说明什么？
2. 它属于“来源”“过程”“错误”“证据”中的哪一种？
3. 是否包含与当前任务无关的个人或版权内容？
4. 删除它后，条目的关键判断是否仍可被核对？

答不清第 1 问的图片通常不应上传；第 3 问为“是”时先裁剪或遮挡。

## R1–R5 图片落位

完整原图和实际 SHA 统一进入 Original Evidence；Prompt 只放可独立作答的无答案文字，Cues 使用 3–5 个短关键词。收件原件保留原路径和字节，不自动归档移动。多图不得复用旧任务附件或伪造路径、SHA。详见 [R1-R5写入规范](../%E6%8F%90%E7%A4%BA%E8%AF%8D/R1-R5%E5%86%99%E5%85%A5%E8%A7%84%E8%8C%83.md)。
