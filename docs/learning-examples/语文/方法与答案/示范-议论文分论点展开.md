# 示范｜语文方法：议论文分论点展开

## 这个类型应该怎么写

语文写作条目要保存“任务约束—中心论点—分论点关系—材料证据—分析链—反方回应—可复用表达”。不能只堆素材或抄范文。

## 成品范例

以下只复制正文到插件创建的 `议论文分论点展开.md`；保留插件 YAML。它是合成示例，不代表已经学习、评分或排期。

```markdown
# 议论文分论点展开

## Source

本文件为合成教学示例，无真实个人作答或学习记录；下列题面与示例说明供核对写法，不冒充教材、试卷或教师批改。

## Prompt

围绕“独立思考需要证据检验”提出两个不重复的分论点，任选一个写出论据与分析衔接；不得虚构名人引语或研究数据。

## Cues

- 中心论点
- 分论点边界
- 证据分析

## Core Idea

**一句话定位（合成示例，非用户事实）**

分论点不是中心论点的同义反复，而是从不同角度回答“为什么、怎么办、在何种边界下成立”，共同推进中心判断。

## Error Boundaries

**素材使用边界（合成示例，非用户事实）**

- 素材先写“它证明什么”，再决定是否使用。
- 不虚构人物言论、时代背景、数据或出处。
- 同一素材不能同时证明相互冲突的结论，除非明确解释角度。

## Solution Skeleton

**示例段落骨架（合成示例，非用户事实）**

证据意识使独立判断免于沦为任性判断。信息越多，未经核验的说法也越容易借情绪传播。若只凭立场选择事实，所谓“独立”便只是偏见的回声。因此，判断不仅要问“我是否认同”，还要问“来源是否可靠、证据能否支撑、反例是否存在”。这使开放获得尺度，也让个人表达承担起应有责任。

## Original Evidence

纯文字合成示例；无实际图片附件，不提供虚构 SHA。原有教学说明已保留在相应区块；不能当成用户已作答证据。

## Detailed Solution

**任务约束（合成示例，非用户事实）**

- 先圈定材料关键词、写作对象、价值冲突与题目限制。
- 中心论点必须回应材料，而不是套用任意主题。

**示例中心论点（合成示例，非用户事实）**

面对信息丰富却判断困难的环境，青年既要保持开放，也要以证据和责任建立独立判断。

**分论点结构（合成示例，非用户事实）**

1. 开放使判断获得更完整的事实基础。
2. 证据意识使判断免于情绪与偏见支配。
3. 责任意识使判断从个人好恶走向公共后果。

三者不是并列口号，而是“信息输入—判断方法—行动边界”的递进链。

**段落展开公式（合成示例，非用户事实）**

分论点句 → 概念解释 → 材料/事实证据 → 因果分析 → 反面或边界 → 回扣中心论点。

## Deep Dive



## Variant Pool

**自检（合成示例，非用户事实）**

1. 每个分论点能否独立推进中心论点？
2. 证据后是否有分析，而非一句“这说明”？
3. 是否回应了材料中的冲突与限制？
```
