# 示范｜语文错题：论证思路题

## 这个类型应该怎么写

阅读条目要把“文本证据—段落功能—逻辑关系—答案表达”对应起来。答案必须能回指原文，不先套题型术语再寻找证据。

## 成品范例

以下只复制正文到插件创建的 `论证思路题.md`；保留插件 YAML。它是合成示例，不代表已经学习、评分或排期。

```markdown
# 论证思路题

## Source

本文件为合成教学示例，无真实个人作答或学习记录；下列题面与示例说明供核对写法，不冒充教材、试卷或教师批改。

## Prompt

阅读合成短文：“有人认为信息越多，判断就越可靠。然而未经核对的信息也会放大误解。例如，把同一传闻的转发当作多份独立证据，就会高估可信度。因此，判断之前应先核对来源是否独立。”概括其论证思路，并逐步指向原句依据。

## Cues

- 段落关系
- 论证动词
- 原文定位

## Core Idea



## Error Boundaries

**易错点（合成示例，非用户事实）**

1. 只复述内容，不写论证功能与层间关系。
2. 只列“举例论证、对比论证”，不说证明了什么。
3. 按自然段机械分层，忽略一个层次跨段或一段多层。
4. 使用原文没有的价值判断。

## Solution Skeleton

**答题链（合成示例，非用户事实）**

先概括第 1 层的内容和功能；再写第 2 层如何承接、转折或深化；随后说明证据与观点的关系；最后写结论如何回扣中心问题。

## Original Evidence

纯文字合成示例；无实际图片附件，不提供虚构 SHA。原有教学说明已保留在相应区块；不能当成用户已作答证据。

## Detailed Solution

**题目要我回答什么（合成示例，非用户事实）**

说明作者如何按一定逻辑推进观点：每一层写了什么、使用什么材料或方法、与前后层是什么关系、最终指向什么结论。

**文本标记法（合成示例，非用户事实）**

- 圈观点句：中心论点、分论点、阶段性结论。
- 划材料：事实、例子、引语、对比对象。
- 标连接：首先、然而、因此、只有、如果等。
- 写功能：提出问题、解释概念、举例证明、对比辨析、回应反方、得出结论。

**表达模板（合成示例，非用户事实）**

文章先【提出/界定……】，接着通过【材料/方法】说明【分论点】，随后从【角度】进一步论证【内容】，最后【回应问题/得出结论】。各层之间构成【并列/递进/因果/转折】关系。

模板中的每个括号都必须由原文证据替换，不能原样套用。

## Variant Pool

**主动回忆（合成示例，非用户事实）**

1. “写了什么”和“怎样论证”有什么区别？
2. 如何判断两个段落是并列还是递进？
3. 答案中的每个动词能否回指具体原文？
```
