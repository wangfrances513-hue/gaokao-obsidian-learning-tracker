## Prompt

两个物体在光滑水平面上沿同一直线发生短时碰撞。说明如何选取研究系统、判断动量守恒条件，并用符号写出碰撞前后关系；机械能是否必然守恒？

## Cues

- 系统边界
- 外力冲量
- 方向约定

## Core Idea

**一句话定位（合成示例，非用户事实）**

对选定系统，在研究过程内合外力冲量为零或可忽略时，系统总动量保持不变。

**对象与过程（合成示例，非用户事实）**

- 系统：明确列出包含哪些物体。
- 过程：从哪个时刻到哪个时刻。
- 正方向：列方程前统一规定。

## Error Boundaries

**条件（合成示例，非用户事实）**

严格条件：$\vec I_{\text{外}}=0$。

常用近似：碰撞时间极短，外力冲量相对内力冲量可忽略。不能把“外力不为零”直接等同于“不守恒”。

**易错边界（合成示例，非用户事实）**

- 研究对象中漏掉相互作用物体。
- 把内力计入系统合外力。
- 标量相加，忽略动量方向。
- 碰撞题同时默认动能守恒。
- 系统动量守恒，却误说每个物体动量不变。

## Solution Skeleton

**判断流程（合成示例，非用户事实）**

1. 圈定系统。
2. 圈定过程。
3. 分析外力冲量，而不只是瞬时外力。
4. 规定正方向。
5. 写初、末状态动量。
6. 与能量关系分别判断；动量守恒不代表机械能守恒。

## Detailed Solution

**方程（合成示例，非用户事实）**

$$
\sum \vec p_{\text{初}}=\sum \vec p_{\text{末}}
$$

一维问题按规定正方向写代数量；速度方向相反时速度取负。
