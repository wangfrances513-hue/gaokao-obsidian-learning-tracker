# 示范｜物理模型：传送带相对运动模型

## 这个类型应该怎么写

物理模型条目强调“模型触发条件—状态阶段—受力—运动方程—转折事件—终止条件”。最好用时间轴或分阶段表，不要背一个固定答案。

## Source

## Prompt

水平传送带以恒定速度 v 向右运动，物块以初速度 u 向右滑入，且 0≤u<v。定性分析相对滑动时摩擦方向、速度相等时的重新判断和是否滑出所需比较量。

## Cues

- 相对速度
- 状态转折
- 位移比较

## Core Idea

**模型触发信号（合成示例，非用户事实）**

物块放上运动传送带，问速度、时间、位移、摩擦方向、是否一起运动或是否滑出。

**建模对象（合成示例，非用户事实）**

- 物块为研究对象；地面为默认参考系。
- 传送带速度为 $v_b$，物块初速度为 $v_0$。
- 摩擦方向由物块相对带面的滑动趋势决定，不由物块对地速度单独决定。

## Error Boundaries

**易错点（合成示例，非用户事实）**

1. 用“摩擦总与运动方向相反”判断方向。
2. 速度相等后仍使用滑动摩擦力。
3. 只算物块位移，不算相对位移，误判是否滑出。
4. 不检查阶段转折时间是否在有效运动区间内。

## Detailed Solution

**阶段一：存在相对滑动（合成示例，非用户事实）**

比较 $v_0$ 与 $v_b$ 的大小和方向，确定相对速度；滑动摩擦力阻碍相对滑动。若水平面且只有摩擦提供水平合力，$a=\pm\mu g$，符号由正方向决定。

**转折事件（合成示例，非用户事实）**

当物块速度达到传送带速度时，相对速度为零。此时必须重新判断受力：静摩擦可能为零，也可能为维持共同加速度而存在；不能继续机械使用 $\mu mg$。

**阶段二：无相对滑动或再次滑动（合成示例，非用户事实）**

根据传送带是否匀速/加速、最大静摩擦是否足够，判断共同运动是否维持。

**终止检查（合成示例，非用户事实）**

- 达到带速前是否已经到达传送带边缘？
- 位移应取对地位移还是相对传送带位移？
- 题目所问时刻属于哪个阶段？
