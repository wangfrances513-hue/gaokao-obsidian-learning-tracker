## Core Idea

**一句话定位（合成示例，非用户事实）**

离子方程式用实际参加反应的微粒表示电解质溶液中的反应本质，不是简单把所有物质都拆成离子。

## Error Boundaries

**条件与边界（合成示例，非用户事实）**

- 同一反应物在溶液、熔融或固态时，拆写方式可能不同。
- 微溶物作反应物且处于溶液状态时需结合题目语境判断；作生成物通常写化学式并标沉淀。
- 酸式盐、多元弱酸、过量/少量条件可能改变实际微粒与产物。
- 氧化还原型离子方程式还要检查电子转移与电荷守恒。

**易错点（合成示例，非用户事实）**

1. 把弱酸、弱碱或水拆开。
2. 漏写沉淀、气体或物态。
3. 只做原子守恒，不做电荷守恒。
4. 忽略“少量/过量”导致产物变化。

## Solution Skeleton

**书写流程（合成示例，非用户事实）**

1. 写：先写正确的分子方程式，并标明物态。
2. 拆：把水溶液中的强电解质拆成离子；单质、氧化物、弱电解质、难溶物、气体和水通常保留化学式。
3. 删：删去等量、同形态出现在两边的旁观离子。
4. 查：检查原子守恒、电荷守恒、条件与物态。

## Detailed Solution

**最小示例（合成示例，非用户事实）**

盐酸与氢氧化钠溶液反应：

$$
\mathrm{H^+ + OH^- \rightarrow H_2O}
$$

宏观现象可能不明显，但微粒层面是 $\mathrm{H^+}$ 与 $\mathrm{OH^-}$ 生成难电离的水。
