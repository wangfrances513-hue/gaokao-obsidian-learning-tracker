## Prompt

设计用已知浓度 NaOH 溶液滴定未知浓度盐酸的纸面方案：说明器材预处理、终点判断、记录量，并分析锥形瓶被待测液润洗的影响。此任务不要求实际操作化学品。

## Core Idea

**实验目的（合成示例，非用户事实）**

用已知浓度的标准酸/碱溶液测定待测碱/酸溶液的浓度。

**原理（合成示例，非用户事实）**

终点附近利用指示剂颜色变化判断反应达到规定终点；按反应计量关系由标准液消耗量计算待测液浓度。终点是观察判据，化学计量点是理论状态，二者可能存在指示剂误差。

## Error Boundaries

**安全（合成示例，非用户事实）**

酸碱溶液避免接触皮肤和眼睛；按实验室要求处理废液。不得仅凭图片推断未知试剂可混合。

## Solution Skeleton

**操作链（合成示例，非用户事实）**

查漏 → 洗涤/润洗 → 装液排气泡 → 初读数 → 移取待测液 → 加指示剂 → 滴定并振荡 → 近终点逐滴加入 → 终点判断 → 末读数 → 平行重复。

## Detailed Solution

**关键器材与预处理（合成示例，非用户事实）**

- 滴定管先查漏，再用待装液润洗。
- 锥形瓶可用蒸馏水洗，但不能用待测液润洗。
- 读数时视线与液面最低点相平，记录初读数与末读数，体积差为消耗量。

**数据表（合成示例，非用户事实）**

| 次数 | 初读数/mL | 末读数/mL | 消耗量/mL | 是否采用 |
|---|---:|---:|---:|---|
| 1 | 原始记录 | 原始记录 | 末−初 | 预滴定/判断 |
| 2 | 原始记录 | 原始记录 | 末−初 | 待判断 |

不得先求平均再掩盖异常值；先按实验规则判断有效平行数据。

**误差方向示例（合成示例，非用户事实）**

滴定管尖嘴有气泡，滴定后气泡消失：读出的标准液体积偏大，若其他条件不变，计算出的待测浓度偏高。

推理链：仪器状态 → 哪个原始量偏大/偏小 → 代入关系式 → 结果方向。
