## Prompt

设计纸面实验比较同种水生植物在不同光照强度下单位时间的净光合作用指标：写出变量、对照、重复及灯距变化的潜在混杂因素。不虚构测量结果。

## Cues

- 自变量
- 单位时间指标
- 混杂因素

## Core Idea

**研究问题（合成示例，非用户事实）**

在其他条件尽量一致时，改变光照强度是否会影响所测植物材料的净光合作用指标？

**假设（合成示例，非用户事实）**

在一定范围内，随光照强度增加，测得的净光合作用指标上升；达到限制因素转移后，上升趋缓。该趋势需由本实验数据检验。

**变量（合成示例，非用户事实）**

- 自变量：光照强度；需说明是直接测量，还是用灯距作为替代指标。
- 因变量：氧气释放、二氧化碳变化或其他明确测量值；不能笼统写“光合作用强弱”。
- 控制变量：材料种类与状态、温度、二氧化碳供应、时间、溶液体积、装置等。

## Error Boundaries

**结论边界（合成示例，非用户事实）**

- 若用灯距表示光强，结论首先针对本装置下的灯距处理，除非实际测量了光强。
- 测得的是净效应时，不能直接等同于总光合作用速率。
- 温度随灯距变化会形成混杂变量，需要隔热或监测。
- 数据只支持测试范围，不支持无限增加光强仍持续上升。

## Solution Skeleton

**证据链（合成示例，非用户事实）**

原始测量值 → 同单位整理 → 必要的速率换算 → 组内重复与离散程度 → 组间趋势 → 在本实验条件下的结论。
