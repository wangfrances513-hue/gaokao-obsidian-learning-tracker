## Core Idea

**一句话定位（合成示例，非用户事实）**

用非谓语结构压缩状语从句时，要同时判断逻辑主语、主动/被动、动作先后和语义关系。

## Error Boundaries

**易错边界（合成示例，非用户事实）**

- 悬垂结构：非谓语的逻辑主语不是主句主语。
- 只按时间先后选形式，漏看主动/被动。
- 为追求“高级句式”而压缩后语义含混。
- `to do` 的目的与结果混淆。

## Solution Skeleton

**决策流程（合成示例，非用户事实）**

1. 找主句主语，确认非谓语动作的逻辑主语与其一致；不一致时考虑独立主格或保留从句。
2. 判断逻辑主语与动词是主动关系还是被动关系。
3. 判断非谓语动作与主句动作是同时、先于还是表示目的/结果。
4. 检查句意：时间、原因、条件、让步、伴随等是否明确。

## Detailed Solution

**常见形式（合成示例，非用户事实）**

- `doing`：常表示主动、进行或伴随。
- `done`：常表示被动或完成状态。
- `having done / having been done`：强调先于主句动作完成。
- `to do`：常表示目的，也可能表示结果或原因，需看结构。

**对比例句（合成示例，非用户事实）**

Seeing the result, the student checked the calculation again.

逻辑主语 `the student` 主动执行 `see`，动作先于或紧接主句动作。

Given more time, the student could improve the essay.

逻辑主语 `the student` 与 `give` 为被动关系，表达条件。
