## Core Idea

**一句话定位（合成示例，非用户事实）**

把二次函数写成 $y=a(x-h)^2+k$，用平方项的非负性直接读出对称轴、顶点和最值。

**核心结论（合成示例，非用户事实）**

- 对称轴：$x=h$。
- 顶点：$(h,k)$。
- $a>0$ 且定义域包含 $h$ 时，函数在 $x=h$ 取得最小值 $k$。
- $a<0$ 且定义域包含 $h$ 时，函数在 $x=h$ 取得最大值 $k$。
- 若定义域不包含 $h$，不能直接说最值是 $k$，要比较区间端点或离 $h$ 最近的可取点。

## Error Boundaries

**易错边界（合成示例，非用户事实）**

1. 漏看定义域，把区间最值当成整条抛物线最值。
2. 配方时常数补偿出错，尤其是括号外还有 $a$。
3. $a<0$ 时把最大值写成最小值。
4. 参数变化导致顶点是否落入区间发生分段。

## Solution Skeleton

**推导链（合成示例，非用户事实）**

$y=ax^2+bx+c=a\left(x+\frac{b}{2a}\right)^2+\frac{4ac-b^2}{4a}$，所以
$h=-\frac{b}{2a}$，$k=\frac{4ac-b^2}{4a}$。
