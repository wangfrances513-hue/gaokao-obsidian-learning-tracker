## Prompt

对函数 f(x)=(x-t)^2，在区间 [0,2] 上求最小值随实数 t 的变化；说明分界和等号归属。

## Cues

- 顶点位置
- 区间端点
- 分界检验

## Core Idea

**识别信号（合成示例，非用户事实）**

“含参数 + 二次函数 + 闭区间 + 最值”意味着：比较顶点与区间的位置，参数分界来自顶点横坐标等于左右端点。

## Error Boundaries

**我的典型错误（合成示例，非用户事实）**

原错误：只写“最小值为 $k$”。

错因：把全定义域最值套到闭区间，未检查顶点是否在区间内。

修正规则：写完顶点式后立刻在数轴上标出 $m,h,n$；没有这一步不进入计算。

## Solution Skeleton

**解题骨架（合成示例，非用户事实）**

1. 配方为 $f(x)=a(x-h)^2+k$。
2. 写明 $a$ 的符号和定义域 $x\in[m,n]$。
3. 解出分界：$h=m$、$h=n$ 对应的参数值。
4. 当 $h<m$：区间位于顶点右侧，按单调性取端点。
5. 当 $m\le h\le n$：顶点在区间内，最值在 $x=h$ 取得。
6. 当 $h>n$：区间位于顶点左侧，按单调性取另一端点。
7. 检查分界点两侧表达式是否衔接，检查等号归属。

## Detailed Solution

**原题抽象（合成示例，非用户事实）**

已知开口方向固定的二次函数，其顶点横坐标随参数变化，求它在固定闭区间上的最小值。

## Deep Dive



## Variant Pool

**迁移规则（合成示例，非用户事实）**

- 开口向下求最大值，结构相同。
- 区间端点含参数时，分界还来自端点相等或区间非空条件。
- 若求最大值且开口向上，通常比较两个端点值，而不是顶点值。

**主动回忆（合成示例，非用户事实）**

1. 参数分段的分界值从哪里来？
2. 为什么不能只比较 $f(m)$ 与 $f(n)$ 来求开口向上的最小值？
3. 等号应放在哪个分段，如何检查遗漏或重叠？

**关联知识（合成示例，非用户事实）**
